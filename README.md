# One-Page Static Web App Template

Mini-projet statique en une seule page, prêt à être poussé sur GitHub.

## Fichiers

- `index.html` : structure principale de la page
- `style.css` : styles responsive et élégants
- `script.js` : menu mobile minimal

## Structure incluse

- Hero
- Contenu principal
- Points clés
- Conclusion

## Personnalisation

Recherchez les blocs marqués comme :

- `[TEXTE DE REMPLACEMENT ...]`
- `[POINT CLÉ DE REMPLACEMENT]`

Remplacez-les par votre vrai bloc de 200 mots et vos résumés.

## Lancement

Ouvrez simplement `index.html` dans un navigateur.
